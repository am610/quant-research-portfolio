# Delivery Roadmap

## Current state

Project 1 is complete. The repository now includes the classical baseline, regime filtering, controlled peer selection, false discovery correction, walk forward pair and principal component models, transaction and borrow costs, execution delay stress, benchmark comparison, exposure diagnostics, bootstrap uncertainty, parameter robustness, time boundary checks, five executed notebooks, and a final research synthesis.

The next development phase is Project 2, calibrated uncertainty aware prediction.

## Phase 1: Research foundation

Target duration: two to three days.

1. Freeze research questions and evaluation rules.
2. Add reproducible market data ingestion.
3. Add chronological data splits and cost assumptions.
4. Implement performance and risk metrics.
5. Add tests for leakage and portfolio accounting.

## Phase 2: Statistical arbitrage study

Target duration: seven to ten days.

1. Implement cointegration and principal component baselines.
2. Add spread diagnostics and regime features.
3. Add walk forward portfolio simulation.
4. Add transaction costs and turnover controls.
5. Add bootstrap uncertainty and stability analysis.
6. Produce a Colab demonstration and research report.

## Phase 3: Uncertainty aware prediction study

Target duration: seven to ten days.

1. Establish linear and tree model baselines.
2. Add temporal neural model and ensemble uncertainty.
3. Evaluate calibration and selective trading.
4. Test robustness during volatility and correlation shifts.
5. Produce a Colab demonstration and research report.

## Phase 4: Limit order book study

Target duration: ten to fourteen days.

1. Select a public event level dataset with durable access.
2. Build order book reconstruction and feature pipelines.
3. Compare logistic, tree, and compact neural baselines.
4. Translate forecasts into executable decisions.
5. Model fees, spread, fills, latency, and adverse selection.
6. Produce a Colab demonstration and research report.

## Phase 5: Research presentation

Target duration: three to five days.

1. Create a visual landing page with one clear story per study.
2. Add animated or interactive performance diagnostics.
3. Add architecture diagrams and concise method summaries.
4. Add badges for tests, reproducibility, and Colab access.
5. Record a brief guided demonstration.

## Definition of research complete

Each study must have a clear hypothesis, a defensible baseline, an untouched test period, realistic costs, uncertainty estimates, documented limitations, automated checks, and a concise visual summary.
